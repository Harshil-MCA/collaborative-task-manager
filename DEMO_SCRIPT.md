# Five-Minute Demonstration Script

Use a local or dedicated assessment database and test credentials from an ignored .env file.

## 0:00–1:00 — Authentication and roles

Start backend and frontend, log in as Manager, show the Manager dashboard, and explain that public signup creates User accounts while advanced roles are provisioned safely.

## 1:00–2:00 — MVP task flow

Create a task with a due date, priority and registered User assignee. Log in as the assigned User, show the task and change it to In Progress and Completed. Log back in as Manager and show the updated status and activity history.

## 2:00–3:00 — Project, requirement and sprint

Open the delivery workspace, create/select a project, create REQ-001 with acceptance criteria, create a planned sprint, and show traceability plus missing test coverage.

## 3:00–4:15 — Development and QA

Allocate a task to a Developer and mark it QA-required. Move it through the development stages. As QA, create a test case and record a failed execution. Create a linked bug, assign it, record fix notes and send it to retest.

## 4:15–5:00 — Retest, sign-off and readiness

Retest once as Fail to show reopening and preserved execution history. Retest as Pass to close the bug and sign off the task. Show that the backend rejects Done before QA checks pass, then show readiness counts.

Do not claim a step was demonstrated unless it was observed in the running application.
